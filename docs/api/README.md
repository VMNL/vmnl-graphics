# VMNL Graphics public API

This book documents the `vmnl_graphics` package, imported as `vmnl_graphics`. It covers the `common`, `d2`, `raw`, `time`, texture source descriptors and GPU resource foundation, window, input, monitor, rendering, and error surfaces. Crate-local items, restricted-visibility items, blanket implementations, and `raw::__private` are outside its scope. Items accepted for the `0.2.0` milestone are marked as such on their pages and are not part of the published `0.1.0` baseline.

Use [concepts](concepts/README.md) for cross-cutting contracts, [reference](reference/README.md) for public items, and [workflows](workflows/README.md) for end-to-end usage. Rustdoc remains canonical for exact signatures and item-local contracts; this book is canonical for navigation, concepts, workflows, maturity, and cross-cutting matrices.

`0.1.0` is the initial API baseline under the [compatibility policy](concepts/maturity_compatibility_and_deprecation.md). The 2D and raw paths render within documented limits. A version number does not establish platform or hardware qualification.
